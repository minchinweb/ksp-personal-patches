# KSP Personal Patches

This is my personal collection of personal patches for KSP 1. They have been
collected from various corners of the internet, and some have been written
personally.

To install, place this repo as `ksp-personal-patches` directly into your
`GameData` folder.

An (incomplete) list of included patches:

- adds a TelStar flags
- Stock
    - add smaller and larger variants of the AIRBRAKES
    - add smaller and larger variants of the RTG
    - adds a "combustion" wheel (as opposed to an All Electric)
    - bump up the capacity of the Science Lab to 6 (from 2)
    - add Crew Reports to the Science Lab
    - girders -- add 0.3m girder (regular and long), 0.3 to 0.6m adapter, 1.25m
      girder (regular and long), 1.25 to 2.5m adapter
    - add Mk0 structural fuseloge
    - structural nodes -- add 0.6m and 1.25m variants
    - fairings -- add 5 and 7.5m variants
    - stack adapters -- add 06-06x2, 06-06x3, 06-06x4, 12-06x2, 12-06x3,
      12-06x4, 25-25x2, 25-25x3, 25-25x4, 37-37x2, 37-37x3, 37-37x4, 50-25x2,
      50-25x3, 50-25x4, 50-50x2, 50-50x3, 50-50x4, 75-75x2, 75-75x3, 75-75x4
    - allow the lanch clamps to supply power to docked ships
    - add TWR to engine descriptions
    - draw fuel gauges for the Ion and Ant engines
    - adds the HubMax connecter in 06, 25, 37, and 50 sizes
    - allows the ISRUs to create Ablator
    - gives minor inbuilt storage to ISRUs (so they are usable if you forget an
      ore tank)
    - fix IVA altimeter hands to match real life
    - respring LY-01 landing gear
    - create LY-25 "medium" landing gear
    - give higher level pilots a fuel effeciency boost
- kOS -- expand memory sizes to support RAMP
- Luciole -- add RemoteTech support
- SystemHeat
    - add support for the (stock) RTG
    - make HeatControl's "Heat Exchanger" function as SystemHeat heat
      exchangers
    - add MEV support
- USI Otter -- retrofit for SunkWorks compatibility
- Stocklike Station Parts eXpansion
    - increate interaction range of 3.75m greenhouse and fish farm
    - fix who can use the telescopes
    - fix model for 2.5m "stand" base
- MEV
    - adds missing drive plum


See also my collection of downloaded patched (mostly flags).

See also my personal CKAN meta repo
(https://github.com/minchinweb/ksp-personal-ckan-meta) that allows you to
install mods that aren't listed on the main CKAN repo.
